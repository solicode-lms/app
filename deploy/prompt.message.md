# Règles de rédaction des messages Soli-LMS

Les messages WhatsApp destinés aux formateurs doivent informer uniquement sur les **fonctionnalités utiles dans Soli-LMS** et sur **ce que le formateur doit faire**.

### À communiquer

* La **fonctionnalité ajoutée, modifiée ou supprimée**.
* Son **objectif ou intérêt pour le formateur**.
* Ce que le **formateur doit faire** ou peut désormais faire dans l’application.
* Les éventuelles **nouvelles règles d’utilisation** à respecter.
* Une information pratique permettant d’utiliser correctement la fonctionnalité.

### À ne pas communiquer

* Les détails techniques de développement.
* Les modifications du serveur, de la base de données ou du code.
* Les technologies, méthodes ou outils utilisés pour implémenter la fonctionnalité.
* Les détails internes qui n’ont aucun impact sur l’utilisation de Soli-LMS.

### Principe

Le message doit répondre simplement à :

**Qu’est-ce qui change ? → Pourquoi ? → Que doit faire le formateur ?**

Le message doit être **court, clair, concret et orienté action**.
