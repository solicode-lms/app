# Capacité : Rédaction Markdown

## 1. Standards de Formatage
- **Titres** : Utiliser un seul `#` par document pour le titre principal. Les sous-sections utilisent `##`, `###`, etc.
- **Listes** : Privilégier les listes à puces pour les énumérations.
- **Code** : Utiliser les blocs de code avec coloration syntaxique (ex: `php`, `bash`, `json`).
- **Mise en évidence** : Utiliser le **gras** pour les termes clés et les `backticks` pour les noms de variables, fichiers ou classes.

## 2. Diagrammes Mermaid
- Utiliser des diagrammes de classes Mermaid (`classDiagram`) pour documenter les modèles de données.
- Utiliser des diagrammes de séquence (`sequenceDiagram`) pour documenter les flux métiers complexes.

## 3. Structure Logique
- Toujours commencer par un résumé ou un objectif clair.
- Diviser le contenu en sections bien définies.
- Utiliser des tableaux pour comparer des données ou lister des propriétés (ex: attributs d'une table).
